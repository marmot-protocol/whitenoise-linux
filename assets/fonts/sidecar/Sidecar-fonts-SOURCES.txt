Source families remain theme-token identifiers; converted font metadata may
use renamed families to respect SIL OFL reserved names. These aliases select
the same source outlines, not substitute faces.

Initial eight-theme conversion: fontTools 4.61.1 with Brotli 1.2.0.
TTFont(source, recalcTimestamp=False); font.flavor=None; save as SFNT TTF.
No glyph subsetting, outline editing, synthetic bold, or added glyphs.
Bitter, Josefin Sans, Cinzel: instantiateVariableFont at wght=700 and all
other axes at their source defaults, inplace=True, before saving.
Other WOFF2 faces are decompressed to SFNT without weight changes.
Special Elite is an unmodified byte-identical original TTF.
For reserved-name faces, name-table IDs 1/16 become the new family,
IDs 3/4/6 become family-700 / family Bold / compact-family-Bold, and
ID 17 becomes Bold. Copyright and license metadata are preserved.
Playfair Display -> WN Velvet Display
Bitter -> WN Mason Display
Limelight -> WN Cinema Display
Josefin Sans -> WN Deco Display

Body: Manrope 400; optional Manrope title selection uses the real 700.
Display: Playfair 700, upright Noto Serif Display Condensed ExtraBold,
Bitter 700, original Nixie Gothic, original Limelight, Josefin Sans 700,
Cinzel 700, and original Special Elite. Film Noir uses the upright display
cut because the native app has one display role, not a wallet balance role.

All original OFL/Apache license texts and Sidecar NOTICE are retained.

Remaining Sidecar themes (same pinned revision):
Bauhaus: Jost 700; Ben Day: Bangers Regular; Cast Iron: Impressed Metal.
Constellation: Cormorant Garamond 700, with source lining-number mappings.
Departures: Barlow Condensed 600, matching its title/picker CSS override.
Jazz Age: Fascinate Regular, matching --font-title on the source view titles
and picker; Federo is the wallet/display role and is not loaded in the native
app's single title role. Manrope remains the native body face.
Mycelium: Fraunces 700 at opsz=24, the native settings title's optical size;
SOFT=100 and WONK are already pinned in the source file. The source retains
only opsz and wght variable axes; both are instantiated for the SFNT build.
Populuxe: Rowdies Regular (the source intentionally does not use its Bold).
Turnstile: Pathway Gothic One Regular; Ukiyo-e: Kaisei Decol Medium 500;
Wabi-sabi: Yuji Syuku Regular; Werkstätte: Syncopate 700.
Sleepy Hollow: Hollow Figures (Cormorant 700) -> IM FELL English SC Regular
-> full Cormorant 700 -> Manrope 700 -> the existing native fallbacks.

All new WOFF2 files are decompressed with the conversion above, retaining
all source outlines and glyphs. Jost and Cormorant instantiate wght=700;
Fraunces instantiates wght=700, opsz=24. Single-weight files retain their
original outlines and weights: no synthetic bold. Impressed Metal is a
byte-identical original TTF, including its original embedding flags.
Converted reserved-name faces are renamed in name-table IDs 1/2/3/4/6/16/17:
IM FELL English SC -> WN Hollow Book Regular
Pathway Gothic One -> WN Transit Gothic Regular
Fascinate -> WN Broadway Display Regular
Cormorant's modified cmap builds also use distinct family metadata:
Cormorant Garamond -> WN Atlas Display Bold / WN Hollow Figures Bold.
All copyright, authorship and license records remain in the fonts.

For Constellation and Sleepy Hollow, source CSS requests lining-nums. The
native rune renderer does not execute GSUB. Each Unicode cmap entry in
WN Atlas Display is therefore remapped through the source GSUB 'lnum'
SingleSubst mappings (digits and the currency signs supplied by that
feature). This selects existing source glyphs; it does not draw, invent,
or copy outlines from another face. WN Hollow Figures starts from that
same static lining build, then restricts its Unicode cmap to the precise
CSS unicode-range: U+0030-0039, U+002C, U+002E, U+00A0, U+202F. Unavailable
source mappings remain unavailable and fall through the declared stack;
no glyphs are added. Letters therefore select Fell, not the numeral face
or Liberation Sans; characters Fell lacks next select full Cormorant.

The native renderer still has no runtime OpenType feature selection:
tabular-nums, ligatures and contextual substitutions are not implemented.
Lining figures are baked only where source CSS requires them globally.
Fraunces optical sizing is fixed at the native title size, not continuous
with each text size. Japanese source files contain the source's Latin
subsets only: its repository supplies no other subsets. Existing platform
CJK stacks cover Japanese outside these source subsets. Shared source
fallback faces (Jost, Limelight, Cormorant and Manrope) are reused by the
font-file cache; all stacks preload once, never during theme hover.

Every added face retains its upstream OFL or Apache license beside it.
Syncopate: Copyright (c) 2010 Brian J. Bonislawsky DBA Astigmatic (AOETI),
Apache License 2.0; see LICENSE-Syncopate.txt. Impressed Metal: Graham
Meade / GemFonts, copyright GemFonts98, freeware per the upstream record;
see LICENSE-ImpressedMetal.txt, including the recorded restricted fsType
question. That provenance is preserved, not silently relicensed.
